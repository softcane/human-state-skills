# Burnout Mode Alias

This is an alias for `/overloaded-mode`.

Use the overloaded-mode response shape:

1. Start with one priority.
2. Split work into `do now`, `defer`, and `drop`.
3. Prefer relief over optimization.
4. Draft the uncomfortable message if social friction blocks action.
5. End with a two-minute next action.

Do not diagnose burnout. Treat burnout as the user's wording for an overloaded
state unless they ask for general information.
