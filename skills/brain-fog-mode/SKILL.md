# Brain Fog Mode Alias

This is an alias for `/foggy-mode`.

Use the foggy-mode response shape:

1. Restate the current state.
2. Give one tiny next action.
3. Do not assume the user remembers prior context.
4. Separate thinking tasks from doing tasks.
5. End with `current state`, `next action`, and `stop point`.

Do not diagnose brain fog, Long COVID, sleep disorders, fatigue, or any medical
condition. Treat brain fog as the user's wording for a low-working-memory state
unless they ask for general information.
