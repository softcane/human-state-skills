# Grounding: Overloaded Mode

This skill adapts response shape only. It is not diagnosis, therapy, medical
care, or burnout treatment.

## Book Anchors

Emily Nagoski and Amelia Nagoski, *Burnout: The Secret to Unlocking the Stress
Cycle*.

The useful translation for an AI skill is not "be a therapist." The useful
translation is:

- Treat exhaustion and overwhelm as real constraints.
- Reduce load before optimizing.
- Make recovery, rest, boundaries, and support legitimate parts of the plan.
- Avoid blaming the user for low capacity.

Greg McKeown, *Essentialism: The Disciplined Pursuit of Less*.

The useful translation for an AI skill is:

- Separate the essential from the merely loud.
- Make tradeoffs explicit.
- Remove work instead of only sequencing work.
- Prefer a small number of deliberate actions over broad optimization.

## Public Source

WHO describes burnout as an occupational phenomenon connected to chronic
workplace stress and explicitly not as a medical condition.

Source: <https://www.who.int/standards/classifications/frequently-asked-questions/burn-out-an-occupational-phenomenon>

AI behavior implication:

- Use `/overloaded-mode` as the broad public skill.
- Keep `/burnout-mode` as an alias, not the canonical frame.
- Do not casually apply burnout outside work contexts as a diagnosis.
- If the user uses the word burnout, accept their wording but do not diagnose.

## Response Contract

Generic AI failure:

- Gives many options.
- Adds productivity advice.
- Explains the whole situation.
- Treats the user as if they have normal capacity.

Overloaded-mode correction:

- Pick one priority.
- Create a do/defer/drop list.
- Draft the hard message.
- End with a two-minute action.
- Make dropping work explicit and acceptable.
