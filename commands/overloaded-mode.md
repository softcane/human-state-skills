description: Activate overloaded mode for the rest of the session.
---

Activate the `overloaded-mode` skill defined in
`skills/overloaded-mode/SKILL.md`.

From this point on, shape replies for overload:

1. Start with one priority.
2. Split work into `do now`, `defer`, and `drop`.
3. Keep options capped.
4. Draft the hard message when useful.
5. End with one two-minute next action.

Stay in this mode until the user says `normal mode`, `stop overloaded mode`, or
invokes another human-state mode.
